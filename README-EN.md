## 📖 About

**SplusPy** is a Python library designed specifically for building **Soroush Plus self-bots** (userbots). It provides a clean, intuitive API for automating your personal Soroush Plus account with ease.

> ⚠️ **Important Note:** This is a **self-bot framework** — it operates on your personal account, not a bot account. Please adhere to Soroush's Terms of Service and use responsibly.

### 🎯 Why SplusPy?

- **Lightweight** — Minimal dependencies, fast execution
- **Intuitive** — Clean API inspired by modern frameworks
- **Feature-rich** — Full control over messages, contacts, and events
- **Async-first** — Built with `asyncio` for high performance

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔐 **Session Management** | Secure session storage with encryption |
| 📨 **Message Handling** | Send, edit, delete, and reply to messages |
| 👥 **Contact Management** | Fetch contacts, groups, and channels |
| 🎯 **Event System** | Decorator-based event handlers |
| ⚡ **Async Support** | Non-blocking operations for speed |
| 🔄 **Auto-Reconnect** | Handles disconnections gracefully |
| 📦 **No Extra Dependencies** | Pure Python with minimal requirements |
