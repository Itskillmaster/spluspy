## 📖 درباره

**اسپلاس‌پای** یک کتابخانه پایتون است که به‌طور خاص برای ساخت **ربات‌های شخصی (سلف‌بات) سروش پلاس** طراحی شده است. این کتابخانه یک API تمیز و شهودی برای خودکارسازی حساب شخصی شما در سروش پلاس ارائه می‌دهد.

> ⚠️ **نکته مهم:** این یک **فریم‌ورک سلف‌بات** است — یعنی روی حساب شخصی شما اجرا می‌شود، نه یک ربات. لطفاً به قوانین سروش احترام بگذارید و مسئولانه استفاده کنید.

### 🎯 چرا اسپلاس‌پای؟

- **سبک** — حداقل وابستگی‌ها، اجرای سریع
- **شهودی** — API تمیز الهام‌گرفته از فریم‌ورک‌های مدرن
- **پرامکانات** — کنترل کامل بر پیام‌ها، مخاطبین و رویدادها
- **همزمان** — ساخته شده با `asyncio` برای عملکرد بالا
